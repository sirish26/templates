# Contributing

Thank you for considering contributing to this Shopify template boilerplate.

Guidelines:
- Fork the repo and open a pull request with a clear description.
- Keep changes focused and include tests where appropriate.
- Run `npm run lint` and `npm run typecheck` before submitting.

Release / publish checklist for maintainers:
- Update `CHANGELOG.md` with user-facing changes.
- Bump the `version` in `package.json`.
- Ensure `build` and `lint` pass in CI.
